# HyperHLE

**HyperHLE** is an independent fork of the touchHLE project. To avoid any confusion with the upstream repository, please review the key characteristics and context of this fork below.

---

## Key Features
* **Clean Codebase:** Developed completely independently without using or copying any code from touchHLE's GerritHub.
* **AI-Assisted Development:** This fork utilizes AI tools and assistance to accelerate development and implement features.
* **Completely Independent:** HyperHLE is a standalone project. It is **not** supported, endorsed, or maintained by the original touchHLE developers (in fact, it is safe to say they strongly dislike it).

---

## Statement on Upstream Developers (hikari_no_yume/ciciplusplus) & Community Policy

The original creators of the project, **hikari_no_yume/ciciplusplus**, actively fight against forks. We find this stance rather foolish; while one might understand hostility toward AI-assisted "vibecoding" forks, they routinely targeted and tried to suppress traditional forks long before AI tools even became common. 

> ⚠️ **IMPORTANT WARNING:**
> If you use HyperHLE or any other fork and are a member of the official touchHLE Discord server, **DO NOT mention any forks there.** Discussing them will result in an immediate, permanent ban.

The true motivations behind ciciplusplus/hikari_no_yume's crusade remain completely baffling to the HyperHLE developers. They seemingly want to eliminate all derivative projects, which is highly contradictory given that touchHLE is licensed under the **Mozilla Public License 2.0 (MPL 2.0)** — a license that explicitly allows the creation of forks. Because of this legal compliance, we will continue to ignore any threats or demands for deletion, as their goals make no legal or logical sense.

Furthermore, we will not fall for or be intimidated by files like `AGENTS.md` or `CLAUDE.md` created in the original repository, which contain absolute nonsense regarding AI interaction with the project.
